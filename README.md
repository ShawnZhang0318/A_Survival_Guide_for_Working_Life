# 打工人生存指南

**在线试玩：** [点击开始游戏](https://shawnzhang0318.github.io/A_Survival_Guide_for_Working_Life/)

做出一个个职场选择，看看你能在打工生活中生存多少天。

## 玩法

- 每回合阅读一张情境卡，选择 A 或 B。
- 选择会影响健康、存款、人际和发量，尽量维持各项状态。
- 任一状态降至 0 或升至 100 时游戏结束，结算时可以保存成绩卡或再玩一局。

## 操作

- 点击或轻触卡片下方的 A、B 按钮。
- 也可以将卡片向左或向右滑动来做选择。
- 电脑上可使用方向键，或按 A、D 键。
